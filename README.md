# Memex 2.0

Tools for scholars.

A directory of ten public tools: five Zotero plugins, Book Helper, three Obsidian plugins, and ScanTailor Spectre with its Zotero companion. Each entry links to the corresponding installation/download section and public source repository.

The category directories provide the detailed installation instructions:

- https://kvarnelis.github.io/zotero-tools/
- https://kvarnelis.github.io/obsidian-tools/

## Preview

Run `python3 -m http.server 8018` in this directory, then open `http://localhost:8018`.

## Publish

GitHub Pages serves the root of the `main` branch at https://kvarnelis.github.io/memex-2/ .

This is plain HTML and CSS, with no build dependencies, JavaScript, images, external fonts, or analytics. Keep requirements and descriptions aligned with each tool’s public documentation. Preserve the section anchors in the linked category pages.
