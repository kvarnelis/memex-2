Zotero

The Zotero plugins listed here target Zotero 9.x and 10.0.x on macOS. Book Helper is a separate Mac application.

New to Zotero plugins? Read the installation guide for how to install a plugin’s .xpi file inside Zotero. Each tool’s link below includes its download and setup steps.

Praetor

Use Codex or Claude Code in Zotero to ask about items, search attachment text, draft notes, and review proposed library changes.

Requires Codex CLI or Claude Code, installed and signed in as a separate command-line program.

NotebookLM Pane

Open Google NotebookLM in Zotero’s item pane and prepare local PDFs for its upload dialog.

Requires internet access and Google sign-in inside the pane. Finish PDF uploads manually in NotebookLM.

Page View

Add single-page reading, two-page spreads, page fitting, and focus mode to Zotero’s PDF reader.

Compact Pane

Show a reduced set of metadata fields by item type, expand the full list when needed, and copy attachment paths from the item menu.

Quiet Theme

Apply a compact interface stylesheet and switch Zotero’s native light or dark appearance.

Restart Zotero after enabling or disabling the interface overlay.

Book Helper

Identify and rename PDF and DRM-free EPUB books, review their metadata, and optionally import them into Zotero.

A Mac application for macOS 13 or later on Apple silicon. Keep Zotero open for optional import.

Obsidian

Read the installation guide for enabling community plugins and installing release files. Each tool’s link below includes its download and setup steps.

Pocket Codex

Use Claude Code, Codex, or Grok in an Obsidian sidebar, with conversations, file context, edits, and provider tools.

Requires Obsidian 1.7.2 or later and an installed, signed-in command-line program for the chosen provider. Manual installation uses four release files. Optional iPhone and iPad remote access requires a Mac host and Tailscale on both devices.

Based on Claudian, created by Yishen Tu. Pocket Codex is maintained independently.

Download and installationSource code

Composition Mode

Write in a paper-style editor with page sizes, margins, type controls, zoom, and page breaks.

Requires Obsidian 1.5.0 or later on desktop. Available through Obsidian’s community plugin directory.

Download and installationSource code

Paragraph Numbers

Show paragraph numbers in the editor gutter for referring to passages in long-form prose.

Requires Obsidian 1.0.0 or later; its manifest supports desktop and mobile. Turn off Obsidian’s built-in line numbers.

Scanning

ScanTailor Spectre

Clean scanned pages and export searchable PDFs, with a Zotero plugin that sends a PDF to ScanTailor and returns the cleaned PDF as a new attachment to the same item.

The Mac application requires macOS 15 or later on Apple silicon. Zotero integration requires both the app and the separate Spectre Loop 0.1.3 plugin for Zotero 9.x or 10.0.x; the app’s bundled plugin is an older version.
